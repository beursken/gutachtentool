// Autokorrektur des Gutachtentools – gilt für alle Klausuren. Je Zeile „falsch => richtig“; Zeilen mit „//“ sind Anmerkungen.
// Zeilen mit „#“ gelten nur vor einer Zahl (Diktat): „Absatz # => Abs. #“ macht aus „Absatz zwei“ bzw. „Absatz 2“ → „Abs. 2“;
// ausgeschriebene Zahlen werden dabei zu Ziffern („Paragraph vier dreiunddreißig“ bzw. „vierhundertdreiunddreißig“ → „§ 433“).
// Berichtigt wird beim Tippen, sobald das Wort abgeschlossen ist (Leerzeichen, Satzzeichen). Groß-/Kleinschreibung zählt;
// am Satzanfang wird „Dei“ entsprechend zu „Die“. Fest eingebaut: „§433“ → „§ 433“, „Abs.1“ → „Abs. 1“ (ebenso Art., Nr., S., lit., Rn.)
// sowie „GRoßbuchstabe“ → „Großbuchstabe“. Keine Berichtigung doppelter Wörter („die die“ ist zulässig) und keine
// Wörterbuch-Ersetzungen von Abkürzungen („StPO“ bleibt). Wörter, die in einer Klausur nie berichtigt werden sollen,
// gehören in deren Ausnahmeliste (Ausnahmen.txt im Klausurordner); Strg+Z nach einer Berichtigung trägt sie dort ein.
